Legend Code للماك

التثبيت ياخذ دقيقتين تقريبًا ومرة وحدة بس.

الطريقة الأسهل ينصح بها

  1. افتح Terminal: اضغط ⌘ + Space واكتب Terminal واضغط Enter.
  2. انسخ الأمر هذا والصقه في Terminal واضغط Enter:
    curl -fsSL https://raw.githubusercontent.com/MATRIX5578/legend-code/main/mac/install-mac.sh | bash
  3. لو طلب Password: اكتب كلمة سر الماك واضغط Enter. (الحروف ما تبان وأنت تكتب، هذا طبيعي)
  4. خلاص. البرنامج ينفتح لحاله، وتلقاه بعدين بالبحث ⌘ + Space ← Legend Code.

Open Terminal (⌘+Space → Terminal), paste the command above, press Enter, type your Mac password if asked. Legend Code opens when done.

من الملفات اللي معك (بدون نت)

  1. افتح Terminal واكتب bash (bash ومسافة).
  2. اسحب ملف install.sh من هذا المجلد وحطه داخل Terminal، واضغط Enter.

Type bash in Terminal, drag install.sh into it, press Enter.

لو صارت مشكلة

  1. "Legend Code is damaged" أو "can't be opened": لا تفتحه من مجلد التنزيلات، ثبّته بالطريقة الأسهل فوق، هي تحل هذا.
  2. طلعت رسالة خطأ: أرسل الملف ~/Library/Logs/LegendCode.log (في Finder اضغط ⌘ + Shift + G والصق المسار).
  3. يشتغل على macOS 11 (Big Sur) وأحدث، على Apple Silicon و Intel.
